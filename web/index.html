Scan with LOTA

In LOTA, set Point Cloud Settings → Min Confidence High Only and Max Depth 3–4 m. Swipe to the capture page, choose N + Depth, set Capture Rate 30 Hz, pick an iCloud folder, then record while driving slowly. Import the LOTA_*.zip here, or run npm run watch -- <iCloud folder> to import automatically.

RoverCapture (legacy app)

Open RoverCapture in Xcode on a Mac, select your signing team, and run on your iPhone. Record a small scene, stop, then upload to your laptop’s LAN address on port 8008.
