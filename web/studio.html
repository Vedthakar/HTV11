How to scan with LOTA
  1. Point Cloud Settings: Min Confidence High Only, Max Depth 3–4 m.
  2. Capture page: N + Depth, 30 Hz, choose an iCloud folder.
  3. Record while driving slowly, then import the LOTA_*.zip.

To import automatically, run npm run watch -- <iCloud folder>.
